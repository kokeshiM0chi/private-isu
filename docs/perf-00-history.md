# 性能改善の履歴

変更ごとの結果をまとめる。比較は同じ遅延の中央値で行う。生の結果は `results/`、全計測の一覧は `results/summary.tsv` にある。

下の表は、同じ条件で一括計測した確定値である。`results/summary.tsv` の `final-` で始まる行に対応する。

| No | 分類 | 内容 | コミット | 遅延なし 中央値（各回） | 基準比 | 100ms 中央値（各回） | 詳細 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01 | `baseline` | 改善なし（基準） | `3f0eb60` | 3,476（3,461 / 3,509 / 3,476） | 1.0倍 | 0点、打ち切り | [perf-01](perf-01-baseline.md) |
| 02 | `db-index` | `comments` と `posts` にインデックス4本 | `3f0eb60`（SQLを適用） | 38,459（33,206 / 38,459 / 39,334） | 11.1倍 | 0点、打ち切り | [perf-02](perf-02-db-index.md) |
| 03 | `db-query` | N+1の解消、`LIMIT`、JOIN | `902e253` | 62,208（62,625 / 59,359 / 62,208） | 17.9倍 | 2,261（2,261 / 2,094 / 2,289） | [レポート](perf-00-report.md) |
| 04 | `app-connection` | `interpolateParams`、接続プール | `9817c01` | 76,485（76,485 / 82,738 / 76,271） | 22.0倍 | 5,951（6,145 / 5,924 / 5,951） | [レポート](perf-00-report.md) |
| 05 | `static` | 画像のファイル化、nginxからの配信 | `18dbd50` | 296,071（251,275 / 296,071 / 299,576） | 85.2倍 | 23,711（23,643 / 23,720 / 23,711） | [レポート](perf-00-report.md) |

## 計測条件が異なる記録

次の記録は、上の表とは比べない。

| 名前 | 理由 |
| --- | --- |
| `baseline-mysql1cpu` | mysqlが1 CPUの制限だったとき |
| `baseline`、`perf-02-db-index`（`final-` なし） | 一括計測の前の記録。Colimaの割り当てや電源の条件が異なる |
| `perf-03-db-query` | バッテリー駆動 |
| `perf-03-db-query-interrupted-by-sleep` | 計測中にMacがスリープした |
